# Travelix 🌍

**Travelix** is a responsive travel booking website template built using **HTML5, CSS3, and Bootstrap**. It provides a clean, user-friendly interface for showcasing travel destinations, managing bookings (static UI), and sharing travel blogs and galleries.

## Features
- **Featured Destinations:** Highlight popular destinations with images and descriptions.  
- **Search Functionality:** Filter destinations or offers.  
- **Booking Interface:** Well-structured, static booking UI.  
- **Gallery & Blog Sections:** Share travel moments visually and textually.  
- **Mobile Responsive:** Fully responsive design with Bootstrap Grid.  
- **Modern Design:** Clean, elegant layout with smooth scrolling and hover effects.

## Technologies
- HTML5  
- CSS3  
- Bootstrap 4
